# 고른 공간

## 주소
https://ctaleez51-art.github.io/splat/

## 어디를 골랐나
- 아파트 단지 안의 한옥 담장 조형물. 보행로를 따라 담장을 끼고 돌며 찍었다.
- 공개해도 되는 곳이라고 판단한 근거: 단지 안 보행로에 놓인 장식용 담장이라 실내가 아니고,
  24장 어디에도 사람이 찍히지 않았다. 아파트 동은 보여도 상관없다.

## 안 나온 자리
- **바닥에 부채꼴로 뻗은 줄무늬** — 걸어가며 찍으면 바닥은 늘 비스듬히 스칠 뿐이라
  같은 자리를 여러 방향에서 못 본다. 거리가 안 정해진 점들이 카메라 시선 방향으로 길게 늘어났다.
- **줄눈 사이 잡초가 뭉개짐** — 사진이 모델에 들어갈 때 500픽셀 남짓으로 줄어든다.
  잡초처럼 가는 것은 그 크기에서 이미 뭉개져 복원할 원본이 없다.
- **멀리 있는 나뭇잎과 건물이 사방으로 늘어짐** — 몇 장에만 들어와 볼 방향이 모자란다.
